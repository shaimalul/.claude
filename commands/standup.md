# Standup Report

Generate a standup report based on the current session's work.

## Instructions

1. Review the current todo list and recent work
2. Summarize what has been completed
3. Identify what is currently in progress
4. Note any blockers or issues encountered
5. Suggest next steps

## Output Format

```markdown
## Standup Report

### Completed
- [List of completed tasks]

### In Progress
- [Current work items]

### Blockers
- [Any issues or blockers]

### Next Steps
- [Recommended next actions]
```

Generate the standup report for the current session.
