# Claude Learning History

Automatic learnings from code reviews. Each entry shows what patterns were identified and learned.

This file is automatically updated by the `/review` and `/gitlab-review` commands when they identify Critical or High severity patterns that should become team standards.

---

## How It Works

1. **Review runs** → Finds issues in code
2. **Feedback loop** → Extracts Critical/High severity patterns
3. **Improvement** → Invokes `/improve-claude` to update configuration
4. **History** → Logs what was learned here
